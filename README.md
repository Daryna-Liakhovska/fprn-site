# Сайт факультету природничих наук НаУКМА

Django-сайт для Факультету природничих наук (ФПрН) НаУКМА. Лабораторна «Сайт факультету», частини 1 і 2.

## Запуск

```bash
python -m venv .venv
source .venv/bin/activate          # Windows: .venv\Scripts\activate
pip install -r requirements.txt
python manage.py migrate           # створює таблиці й одразу наповнює сайт даними
python manage.py createsuperuser   # для доступу до /admin/
python manage.py runserver
```

Тести: `python manage.py test`.

Перевірка відкату (частина 2, п. 5):

```bash
python manage.py migrate exchange zero
python manage.py migrate
```

## Сторінки

| URL | Що показує |
|---|---|
| `/` | Опис факультету, контакти, перелік освітніх програм |
| `/programs/` | Спеціальності: назва, код, перші 50 слів опису, координатор набору та його контакт |
| `/programs/<id>/` | Повний опис, список дисциплін, випускова кафедра |
| `/departments/` | Кафедри: назва, завідувач, спеціальності, для яких кафедра випускова |
| `/departments/<id>/` | Те саме + список викладачів (ім'я, посада, науковий ступінь) |
| `/exchange/` | Програми академічного обміну зі статусом прийому та фільтром за країною |
| `/admin/` | Кафедри, спеціальності, викладачі, текст головної сторінки, програми обміну |

Текст головної сторінки зберігається в БД у моделі `HomePage`: це один запис (singleton), який редагується з адмінки. Додати другий запис або видалити наявний адмінка не дозволяє.

## Структура

- `faculty/` — частина 1: моделі `HomePage`, `Department`, `Program`, `Teacher`. Міграція `0002_seed_data` заповнює сайт реальними даними.
- `exchange/` — частина 2: модель `ExchangeProgram` і ланцюжок міграцій. Опис рішень — у [`ANSWERS.md`](ANSWERS.md).
- `templates/`, `static/css/style.css` — шаблони та стилі.

## Чому саме ФПрН

На сторінці «Факультети» сайту НаУКМА (ukma.edu.ua → Освіта → Факультети) власні сайти мають лише ФІ (fin.ukma.edu.ua), ФПвН (law.ukma.edu.ua), Школа охорони здоров'я, KMA Pro та kmbs. Для ФГН, ФЕН, ФСНСТ і ФПрН є тільки сторінки всередині старого Joomla-сайту університету.

ФПрН обрано, бо там інформація розкидана найсильніше:

- **Немає єдиного переліку спеціальностей.** Бакалаврські програми ведуть на сторінки ECTS-каталогу (`/ects/...`), а актуальні описи, коди нового класифікатора (Е1, Е2, Е3, Е5) і координаторів набору видно лише на vstup.ukma.edu.ua. На сторінці факультету ще стоять старі коди (101, 102, 104).
- **Склад кафедр оформлено по-різному.** На кафедрі біології завідувач і викладачі є лише на окремій підсторінці «Викладачі». Кафедра фізико-математичних наук перелічує викладачів прямо на головній сторінці кафедри. У кафедри хімії ступені скорочено до «к.н./д.н.». Сторінка кафедри екології частково не завантажується.
- **Email-адреси приховано JavaScript-захистом Joomla**, тому без JS контактів не видно.
- **Немає зв'язку «кафедра → спеціальності».** Щоб дізнатися, яка кафедра випускова для програми, треба відкрити сторінку вступу.
- **Немає розділу про академічну мобільність.** Згадки про Erasmus+ розкидані по описах кафедр, а єдиного списку партнерів, дедлайнів і кількості місць немає. Тому розділ `/exchange/` з частини 2 для цього факультету справді корисний.

Новий сайт збирає ці дані в одному місці і пов'язує їх: спеціальність → випускова кафедра → викладачі.

## Джерела даних

- Сторінка факультету та кафедр: <https://www.ukma.edu.ua/index.php/osvita/fakulteti/fprn>
- Викладачі кафедр: підсторінки `.../kafedra-biologiji/vykladachi`, `.../kafedra-khimiji/vykladachi`, `.../kafedra-ekologiji/vykladachi`, `.../phys-math`
- Освітні програми, координатори набору: <https://vstup.ukma.edu.ua> (сторінки програм Е1, Е2, Е3, Е5)

Списки дисциплін для хімії й фізики складено за загальною структурою програм, бо на сторінках вступу їх наведено не повністю. Описи програм обміну складено за загальновідомими фактами про університети-партнери.
